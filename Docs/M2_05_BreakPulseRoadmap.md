## 1. 最终玩法与数值归属

玩家获得第四类主动能力：带冷却的短范围破势。原三段攻击继续造成生命伤害，正式破势主要削减对方Poise；Poise耗尽时进入一次可辨识的破势反应，阻断当前攻击 / 移动，随后按明确恢复规则退出。死亡始终最高优先级；普通受击、破势与死亡不能各自启动一套相互覆盖的Montage。

暂定可调值：MaxPoise100、一次破势削减60、范围300cm、冷却6秒，默认不附带Health伤害；F键已在C2-01核对并固定为唯一Started入口。以上是后续玩法调试起点，A / B已实现Poise100/100与归零反应 / 回填，C2-02已接正式范围并完成两次F归零 / 恢复；原6秒冷却不重复提交。AttackPower属性留需要将攻击数值与装备统一时再设计，不为了凑属性数量提前增加无消费者字段。

成功接受动作的唯一提交点开始冷却；配置非法 / 死亡 / 忙碌 / 冷却中请求拒绝，不留下冷却或忙碌状态。接受后空挥、被打断或目标离开，不退款冷却；动画生效通知只允许当前激活提交一次范围结算。查询 / Notify不直接改Poise，以攻击者ASC创建独立GE Spec并通过合法结算入口写属性。

## 3. 架构、状态与性能

- **属性集**只维护Poise / MaxPoise合法数值，不拥有敌人AI、Montage或Widget。Character一次初始化并发布公共Ready，非法Poise不能先初始化前两组。A已验收的合法0仍Ready，不等同死亡；B1交付可请求状态，B2已接耗尽事件与恢复。
- **反应层**负责从属性事件和身体生命周期决定是否进入 / 退出一次破势，保持当前身体与本轮身份，精确释放自己持有的Tag / 委托 / Timer / Ability Handle。回填与结束回调不能递归开启新破势。
- **GA_BreakPulse**负责动作、唯一生效点、配置和冷却事务；范围查询只在本次合法生效点执行，按身份去重并排除自身 / 同阵营 / 无效或死亡目标。墙体遮挡仍是最终可命中条件，不能只靠Overlap返回目标就穿墙结算。
- **已有能力与AI**按统一状态门控判断是否接受请求。新Stunned规则必须核对攻击 / 闪避 / 治疗 / E / 移动与AI；不只在新技能内部加一个Tag就声称完成互斥。
- **UI**只观察可用性 / 冷却快照，禁止自己扣资源或加Tag。需要显示秒数时仅可见且冷却活动期间有限刷新，结束即停；不每帧扫描全部ASC / Actor。

A不加入常驻更新；范围能力不逐帧扫描关卡。必要效果和状态恢复基于世界时间，Pause冻结、EndPlay取消。没有新的性能测量时，只说明更新策略，不宣称FPS提高。
