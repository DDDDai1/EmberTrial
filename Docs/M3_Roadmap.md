## 2. 静态数据、逻辑状态与身体效果分开

| 所有者与交付边界 | 内容 | 寿命 |
| --- | --- | --- |
| UETRelicDefinition | 稳定ID、文本、图标软引用、槽位资格、加法参数 | 静态资源，不记录拥有 / 当前数值 |
| GameInstance层遗物库存域 | 拥有ID集合、已提交的两槽ID；不存ASC / Widget或GE句柄 | 当前进程，跨OpenLevel；NewRun确认后重置 |
| Character装备组件 | 对当前ASC应用后的句柄、装备就绪 / 提交协议 | 当前身体，结束精确移除自己效果 |
| LocalPlayer UI Presenter / View | 列表、临时选择 / 预览、焦点；发意图、显示业务结果 | 当前页面 / 本地玩家，不提交伪造成功 |

Controller会随切图销毁，不能单靠Controller字段保存Continue装备。原RunSession仍只负责地图 / 检查点 / 切图；后续独立库存域与其确认点协作，不把所有东西都塞进RunSession。01 / 02A静态与纯计算、B实际属性 / GE已验收；GI库存合同已由C1验收，身体持有者由C2-01验收、完整事务由C2-02验收。当前祭坛页面与受限PIE入口复用同一真实事务，普通P只读；GameplayReady仍指四组基础，EquipmentReady单独表达装备同步。
