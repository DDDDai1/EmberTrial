## 1. 最终要形成的功能

玩家通过正式 GAS 能力播放一次攻击，只在命中窗口内进行扫掠。同一次攻击对同一目标只结算一次真实 Gameplay Effect；目标生命变化符合既有属性规则。受击可以取消当前攻击；生命归零后只执行一次死亡处理，停止行动、关闭检测并清理能力。玩家的属性变化由已有 Presenter / HUD 展示。

此阶段保留单段招式。连击、体力、无敌窗、复杂敌人 AI、正式重试流程在对应后续阶段扩展；M1-04 不以堆叠这些功能作为完成条件。

## 3. 状态和职责

- **ASC / Ability**：正式攻击的激活、活动标签、完成 / 取消与任务清理；不再在角色蓝图保存一份“正在正式攻击”布尔变量。
- **Character**：持有本身体的ASC，授予并保存Ability Spec Handle，接受输入命令，协调身体移动和结束生命周期。
- **Blueprint**：选择能力子类 / Montage、映射按键、调用C++命令和查询；不以Delay结束能力或手动增删攻击Tag。
- **命中组件与NotifyState（B）**：C++做扫掠、来源校验与目标去重，动画资产描述窗口时点。
- **伤害与生命（B / C）**：伤害通过Gameplay Effect落到现有AttributeSet；死亡是独立规则，不能由HUD见到0血就执行。
- **Presenter / HUD**：沿用已验收的只读数据流，能力层不Include UI模块，也不直接修改进度条。
