# M7-05B-2 灰烬试炼界面重设计

基于已提交的 M7-05B（`8784016`）重做主菜单、暂停和遗物界面，让三页分别服务于**进入试炼、返回战斗、比较装备**。以正式路线的暗石材、祭坛的氧化铜边和灰烬短刃的暖光为视觉来源。首屏展示试炼空间，菜单层级靠留白与字重辨识，数值区保持干净、可扫读。

M7-05B 的提交作为视觉对照基线。最终反馈与验收集中在本章，完成后归入 `Docs/Reports/M7_05B_2_Verification.md`。本篇的规格和画面都是实施目标。

## 1. 先定画面，再批量接入

先按 1920 × 1080 做主菜单默认态、暂停默认态和祭坛选中逆焰刻印三张稿。确认文字密度、主次操作和画面氛围后，再用同一套规则整理主菜单、暂停中的设置子页。实际字号、焦点和控件间距以 UE 游戏窗口为准。

| 页面 | 当前问题 | 本次改动 |
| --- | --- | --- |
| 主菜单 | 三个大按钮和右侧设置卡同时抢注意力 | 左侧行动区、右侧正式路线取景，设置进入独立页 |
| 暂停 | 动作、遗物、设置三个区域同时占用空间 | 首屏只有一张窄面板，保留场景，遗物与设置经入口展开 |
| 遗物 | 选择、说明、数值和装卸层级接近 | 先认槽位和模式，再选遗物、对比数值，最后在底栏确认 |

### 1.1 色彩、轮廓与反馈

颜色统一填 **Hex sRGB**。取景右侧可以较亮，文字区用稳定底色。倒角取 2–4 个逻辑单位，分隔线 1 个单位。石纹只出现在大面积底图或标题边缘，比较表、输入框和按钮文字下方用纯净底色。

| 角色 | Hex sRGB | 用法 |
| --- | --- | --- |
| 暗底 / 石面 / 抬起层 | `101215FF` / `191D22FF` / `242A30FF` | 左遮罩、卡面、列表选中层或次按钮底 |
| 正文 / 次要 / 禁用文字 | `F3EBDDFF` / `BDB6ABFF` / `827E77FF` | 正文与动态值、次要说明、带原因的禁用态 |
| 分隔 / 默认边 | `49423AFF` / `64605AFF` | 面板细线与小面积控件边 |
| 铜色 / 焦点 | `C58D54FF` / `F2C887FF` | 选中刻线、少量主题装饰、键盘焦点框 |
| 主按钮 Normal / Hover / Pressed | `AD7445FF` / `B98651FF` / `A76F43FF` | 仅当前主动作用实色，文字用 `100D0AFF` |
| 正值 / 负值 | `B2CA8DFF` / `E5A18CFF` | 遗物差值同时显示 `+`、`−`，持平显示 `—` |

焦点用 **2 单位亮边**，悬停抬高一档底色，已选用 **2 单位铜色侧线**与明亮字重。禁用态保留可读的原因文本。在实机图上测透底后的颜色，可操作标签与关键文字以 **4.5:1** 为本项目目标。[W3C 正文对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

### 1.2 字体、字距、行距

中文展示标题可用 **思源宋体 SC Semibold**，正文用**思源黑体 SC Regular / Medium**。第一轮也可用已通过中文显示验证的项目字体跑样板。标题以字重和留白形成层级，遗物长说明、按钮和设置字段用清晰的正文字体。西文、数字和标点核对回退字体。比较表把数值放在固定宽度、右对齐的列内。[思源宋体发行页](https://github.com/adobe-fonts/source-han-serif/releases) · [思源黑体发行页](https://github.com/adobe-fonts/source-han-sans/releases)

| 层级 | UMG Font Size 起点 | Letter Spacing 起点 | Line Height Percentage | 用途 |
| --- | ---: | ---: | ---: | --- |
| 主标题 | 58 | 40 | 1.00 | 灰烬试炼，一行 |
| 页标题 | 32 | 16 | 1.00 | 试炼暂停、遗物祭坛、设置 |
| 区标题 / 遗物名 | 22 / 24 | 0 | 1.10 | 比较区、当前选择 |
| 操作 / 数值 | 18 / 17 | 0 | 1.15 | 按钮、属性和数值 |
| 正文 / 辅助 | 17 / 15 | 0 | 1.30 / 1.20 | 遗物说明、禁用原因和按键提示 |

使用 **4 / 8 / 12 / 16 / 24 / 32 / 48** 的间距梯度。标题到说明 **8**，列表条目的两层文字之间 **4**，区块之间 **24–32**，内容到面板边界 **24**。字体字距、行距和 Slot Padding 分开调整。长中文开启自动换行，`Wrap Text At=0` 由父栏约束，避免固定值与小窗列宽冲突。表中字号是 Designer 的起点，字体面和 DPI 会影响实际读数。[Epic UMG 字体设置](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-fonts-with-umg?application_version=5.5) · [Epic UE 5.5 DPI Scaling](https://dev.epicgames.com/documentation/en-us/unreal-engine/dpi-scaling-in-unreal-engine?application_version=5.5)

## 2. 三页构图

数值均为 UMG 逻辑单位。先在项目现有 DPI 曲线上读取可用宽度。使用 Anchor 和最大宽度约束，表格、正文靠 Fill / Auto 分配。1280 × 720 时先缩外边距和列表列宽，正文继续沿用字号层级。

### 2.1 主菜单

**左侧给阅读与操作，右侧给场景。** 左安全边距 96（小窗 40），操作列宽 320–360。标题和按钮统一左对齐，标题到操作组留 40。按钮可点击区高 50–54，组内间距 8，退出与主要操作间隔 20。左侧深底向画面中部过渡，右侧只保留一个主体。正式图取景时优先选石门、短刃或祭坛。

```text
┌────────────────────────────────────────────────────┐
│   灰烬试炼                        正式路线取景      │
│                                    主体靠右          │
│   继续本次试炼                                      │
│   开始新试炼                                        │
│   设置                                              │
│                                                     │
│   退出游戏                                          │
└────────────────────────────────────────────────────┘
```

有可用存档时，继续为首焦点和主按钮。无可用存档时，直接突出开始，继续显示真实不可用原因。从设置专页返回时，把焦点还给首屏的“设置”入口。新试炼确认沿用现有业务，选择明确的取消动作作为首焦点。背景用 Fill 裁切，小窗里主体保持在右侧。标题、退出和状态由 UMG 文字绘制。

### 2.2 暂停

**左侧窄面板叠加已暂停的场景。** 面板宽 328–360，内边距 24，左距 64（小窗 32），垂直居中。面板外用约 55% 深色遮罩，面板本身用实底。主动作“继续试炼”，其次“查看遗物”“设置”，底部隔开“返回主菜单”。

```text
┌────────────────────────────────────────────────────┐
│  ┌────────────────┐                                │
│  │ 试炼暂停       │                                │
│  │ 继续试炼       │        暂停时的当前游戏场景     │
│  │ 查看遗物       │                                │
│  │ 设置           │                                │
│  │ ───────────    │                                │
│  │ 返回主菜单     │                                │
│  │ P 继续         │                                │
│  └────────────────┘                                │
└────────────────────────────────────────────────────┘
```

普通 P 默认落在继续。查看遗物后显示只读，返回暂停时恢复入口焦点。E 祭坛直接进入可装备页，离开仍由 `ETFailureFlowComponent` 释放祭坛权限、恢复输入和解暂停。P 松开沿用原恢复路径。子页通过“返回”或 Esc 退一层，文本输入、已展开下拉框和显示预览有优先处理权。Esc 还需在独立游戏中检查，避免被 PIE 编辑器接管。

### 2.3 遗物与祭坛

**整页工作面板，左列表、右详情、底部固定操作。** 面板最大宽 **1120**，最小安全边距 **32**。标题、模式提示和槽位放在顶部。左列 **280**（小窗可到 **240**），列距 **24**，右列 Fill。

```text
┌────────────────────────────────────────────────────┐
│ 遗物祭坛                     槽 A [已装备]  槽 B […] │
│ ────────────────────────────────────────────────── │
│ 搜索遗物   筛选  排序         逆焰刻印               │
│ 生息余烬                     遗物说明               │
│ 逆焰刻印                     属性      当前 → 比较  │
│ ……                           每行显示增减差值       │
│ ────────────────────────────────────────────────── │
│ 返回             操作反馈       卸下该槽  确认装备  │
└────────────────────────────────────────────────────┘
```

1. A / B 槽要同时区分比较目标和装备状态。空槽显示“未装备”。如果现有 View 数据缺少名称，从原装备快照补投影。页面只发送选槽和装卸意图。
2. 搜索、筛选和排序沿用原逻辑。行高从 52–60 起步，行名和装备徽记分行，上下键有可见焦点。搜索为空时显示空状态，仍能卸下当前槽装备。
3. 右栏先读名称和说明，再按顺序显示最大生命、轻攻击、治疗、体力恢复、破势伤害共五行。采用固定列宽与右对齐。当前值和预览从原 Presenter 读取。
4. 底栏位于详情 Scroll Box 外，高约 64，可随两行反馈增高。只读页提示“仅查看 · 在祭坛可更换”。祭坛页显示真实提交反馈，提交中锁定重复点击。
5. 1280 × 720 时优先保住头部槽位、左列和底栏，详情可向下滚动。使用逆焰刻印与裂势印的实际说明检查换行和操作区域。

## 3. UE 接入顺序

1. 以已提交的 M7-05B 为出发点，用同分辨率保存主菜单、P 页与 E 祭坛截图。先用纯色面板和项目取景确定构图，再接真实状态。
2. 在 `WBP_ETMainMenu` 和 `WBP_PauseMenu` 分别用 **WidgetSwitcher** 装配 `Home / Settings`、`Pause / Settings / Relics`。移动现有控件，保持 `StartButton`、`ContinueButton`、`QuitButton`、`BTN_Resume`、`MainMenuButton`、`StatusText`、`RelicPanel` 和四类设置实例唯一。原生 BindWidget 沿用现有类型和对象名。新增“设置”“查看遗物”“返回”只发页面导航意图。[Epic UE 5.5 WidgetSwitcher](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/Runtime/UMG/Components/UWidgetSwitcher?application_version=5.5)
3. 设置专页复用四个原生 WBP，左侧选四个分类，右侧展示一个可滚动内容区。切分类和离开设置时撤销未确认的显示预览、恢复草稿基线。现有 `ETVideoSettingsWidget::CloseView` 会取消预览并解绑，若实例保留在 WidgetSwitcher，需增加页切换的清理与恢复入口。切页焦点落在当前页的首个可用项，返回恢复入口焦点。
4. `WBP_ETRelicPanel` 与 `WBP_ETRelicListEntry` 继续用现有 Presenter 和可复用列表条目。移动列表、详情、确认、卸装实例，保留裁切滚动和选中状态。比较表采用 Presenter 提供的数据。场景和资源状态发生变化时由事件刷新。
5. 若做动效，先试 **120–160 ms** 的淡入和轻移。操作和焦点当帧生效，验证世界暂停时动画与按钮仍可用。实机复查失败重试、胜利再玩和返回菜单，确认宿主页切换正常。
6. 子 WBP 先编译保存，再编译宿主并运行 **Validate Assets**。后台进程修改过资产时，确认当前编辑器已从磁盘重载再运行 PIE。新增原生导航时执行 Editor 和 Game 构建。

| UMG 装配顺序 | 放置规则 | 首次应看到的结果 |
| --- | --- | --- |
| 主菜单宿主 | `Overlay → 主图、左遮罩、WidgetSwitcher`。Home 的 `VerticalBox` 放标题、四个动作和原 `StatusText`。Settings 收纳原四类设置实例 | 首屏保留完整取景和四个动作，分类页一次显示一类设置 |
| 暂停宿主 | `Overlay → 场景遮罩、WidgetSwitcher`。Pause 页放操作栏，Relics 页放已有 `RelicPanel`，Settings 页放原四类设置实例 | 普通 P 显示窄操作栏，E 从祭坛直接显示可装备页 |
| 遗物面板 | `Border → VerticalBox → 页头 Auto、正文 Fill、底栏 Auto`。正文是 `HorizontalBox → 列表列、详情 ScrollBox`。确认和卸装移到底栏 | 两槽和提交按钮位置稳定，列表与长详情各自滚动 |

本轮优先用 **主菜单默认态**做视觉样板，确认后依次接暂停和祭坛。样板画面用当前模型和路线素材占位，终版主菜单图单独取景。能在界面里操作的控件、文字和焦点均由 UE 实现。

## 4. 素材与工具

第一轮只需 **UE 5.5、已有场景资产与一次正式路线取景**。先用实机画面决定构图，工具按下表的交付需求选择。

| 资产 | 来源与规格 | 工具 |
| --- | --- | --- |
| 主菜单背景 1 张 | 在 `L_ET_TrialRoute` 用固定视角或 Cine Camera 取景，1920 × 1080，主体靠右，无 HUD、调试字与编辑器边框。保留原图和已裁切版 | UE 取景。已有 PS 可做压亮点、遮罩和裁切，首轮无需购置 |
| 可选主题刻印 1 枚 | 取自双槽祭坛正面的双三角形，64–128 px、透明边留足，保证小尺寸可辨 | UE 简单形状或 PS，沿用项目自己的图形 |
| 可选遗物图标 6 枚 | 治疗、体力恢复、破势等用易分辨的物件剪影。每件 128 × 128 RGBA PNG，先做一枚对风格。通过 Data Asset 的原 Icon 字段接入并检查列表中的小尺寸辨识度 | 现有 Blender 出物件图，UE 或 PS 排整齐 |
| 展示标题和正文 | 现有字体先试排。切换思源字体时选简中地区字形与实际权重，保留版本和许可证，核对包体与常见标点 | UE Font / Font Face，可用已有 PS 或 Figma 对照字体节奏 |

保留背景和图标的源文件与运行图。PS 的 Export As 选 PNG 时核对透明度和 sRGB 转换。UE 色彩图启用 sRGB，界面图采用适合 UI 的纹理压缩。新增资产登记来源、版本、裁切和许可证。[Adobe Photoshop 导出设置](https://helpx.adobe.com/in/photoshop/desktop/save-and-export/export-files-to-different-formats/export-settings-and-export-location-preferences.html) · [思源宋体 OFL](https://github.com/adobe-fonts/source-han-serif/blob/master/LICENSE.txt) · [思源黑体 OFL](https://github.com/adobe-fonts/source-han-sans/blob/master/LICENSE.txt)

预计视觉样板 **1–2 小时**，UE 三页接入 **3–5 小时**，实机调整 **1–2 小时**。最有用的配合是提供一次正式路线的无 UI 取景，前景保留铜边或短刃暖光，并记录机位。

## 5. 最终验收与反馈

最终反馈归入 **M7-05B-2**。前后对照使用相同分辨率。以 **1920 × 1080**、**1280 × 720** 两种实际游戏窗口为基本矩阵，有超宽显示器时补查首屏裁切。

| 组别 | 通过标准 |
| --- | --- |
| 视觉 | 三页色彩、字阶和焦点一致，第一眼能辨认当前主操作。缩窗时主按钮、标题、长文本和数值无裁切或重叠，内容横向无需滚动 |
| 主菜单 | 有档与无档首焦点正确。开始确认、继续、退出、设置进出均有效 |
| 暂停与设置 | P 恢复，返回主菜单正常。Tab 能进出子页并滚入，Esc 返回次序正确。独立窗口核对暂存、应用和显示预览切页回滚 |
| 遗物 | P 只读，E 可装卸。逆焰刻印与裂势印说明及五项数值完整。测试换槽、搜索空态、实际装卸与返回焦点，小窗底栏始终可见 |
| 胜败与构建 | 失败重试、胜利再玩及返回菜单可用。受影响的 WBP 均 Validate，原设置和遗物用例通过，需要时补 Editor / Game 构建 |
