## 结论与后续

音频路径是当前切图开销的重要组成部分。这个对照关闭了整个音频设备路径，尚无法把差值归到 Sound Mix、Mixer 队列或硬件回调中的某一项。两个进程各三次采样，且正常组先跑，电源状态也未独立确认。这里的差值仅用于本机诊断，正式游戏继续正常启用音频。

后续可在两组都启用音频的前提下，对比 Windows Mixer 实际回调缓冲 1024 与 512 帧，同时检查设备实际采用的值、Flush 时长与声音是否出现爆音或掉音。当前配置 1024 帧 / 48 kHz 对应约 21.33 ms 的音频块，量级与部分 Flush 接近，仍需实测才可建立因果关系。

原始证据在 `Artifacts/M6_03/Runtime`。按 UE 5.5.4 Trace 协议解码的 CPU 区间、Region、两组对照 CSV 和正常组的任务线程导出在 `Artifacts/M6_03/Analysis`。六次试炼 `LoadMap` 的 Trace 时长与对应日志记录相差均低于 1 ms。
