## 本阶段值得复盘的点

- 范围事件之外，需要覆盖初始状态；登记同时保留销毁清理所需的接收者引用。
- 按键单次触发与目标拒绝重复执行分别验证，不能用结果只成功一次来代替输入频率检查。
- 世界暂停、输入模式、鼠标光标、键盘焦点是不同状态；恢复操作要成对收尾。
- UI 通过继续请求通知创建者，创建一次 / 绑定一次，避免重复构建或重复订阅。
- Reference / Target 和生命周期边界必须明确，Widget 有效与 Gameplay 目标有效是两层检查。
