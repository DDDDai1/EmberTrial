## 实现期间的一条已解决编译错误

日志 UTC 09:08:45 出现一条 BP_ThirdPersonCharacter 的编译错误：当前 Self 不是 WBP_InteractionPrompt，Widget 调用的 Target 需要连接。此后日志有角色蓝图保存、正常 PIE 和交互成功记录，用户最终明确确认 Compile 与实机测试通过，因此归为实现中途已解决的问题，不视为当前阻塞。

复盘要点：**函数在哪个蓝图执行，与它要操作哪个对象，是两件事。** 在角色里调用 Widget 函数，Target 要接 PromptWidget；不能默认使用角色 Self。现有日志不足以证明具体是哪一个调用节点漏接，不编造节点名称或修复操作细节。

整个日志中 `Blueprint Runtime Error`、`Accessed None`、`LogScript.*Error`、`Fatal error` 匹配数为 0；`LogBlueprint.*Error` 匹配数为 1，即上面的中途编译错误。不把它描述成“全部日志零错误”。
