## 1. 最终行为与职责

- 三正式身体各一份Poise / MaxPoise，默认100/100；全部出生配置通过才发布Ready，0合法且不等同死亡，换控不重置同一身体。
- Poise归零只请求一次GAS Stagger，1.2游戏秒期间取消 / 阻断五项动作并停止敌人追击 / 攻击；存活结束经GE回填当前Max，死亡 / 失活 / EndPlay不回填。
- 正式F以Enhanced Input Started单次请求，站定地面、默认水平速度≤3；接受后提交一次6秒冷却。空放、受击取消与未命中不退款。
- 原生无状态Notify在12帧/.4秒只路由当前Montage实例的一次结算；300cm球体候选按身体去重，经中心距离、阵营、状态与Visibility过滤，逐目标独立GE扣60Poise，不伤Health。施放取消停止剩余目标，已应用结果不回滚。
- 破势HUD读真实GAS；仅可见冷却期间每.10游戏秒刷新，无Widget Tick / Text Binding；暂停冻结，重建View不重置冷却，旧来源 / 代次不污染新身体。

四类主动能力已接：轻攻击、方向闪避、有限次数治疗、范围破势。它们仍需后续锁定、整章集成、当前包与表现打磨；旧Control Rig / Quinn素材继续作为占位。
