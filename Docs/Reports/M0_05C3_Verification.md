## 4. M0-05 最终路线

结合 A / B 的 UE 资产核对、C1 / C2 的实机与自动回归，以及本次组合录像，后续采用：

1. **共享模板骨架。** 当前玩家 SKM_Quinn_Simple 使用 SK_Mannequin；ABP_Quinn 继承 ABP_Manny，复用已有 DefaultSlot。
2. **Control Rig 制作原地占位动作。** 攻击、闪避、受击分别烘焙为约 1.033 / 0.700 / 0.633 秒 AS，再由 Montage 播放；后续资源替换遵守骨架和动作契约。
3. **CharacterMovement 管位移。** AS 中 root 不漂移；闪避使用 Root Motion Source 管理实际胶囊移动，当前 150 cm / 0.30 s。碰撞、坡面、暂停、打断和不同步长已有之前的验证记录。
4. **动作组件管状态和结束。** 正常结束、受击打断、取消及 EndPlay 共用清理路径；用位移源身份和播放序号处理生命周期。位移结束与动作解锁是两个独立时点。
5. **蓝图管输入接线与表现配置。** 现有输入 / 暂停 / 交互在组合实机中可继续使用；正式战斗框架、命中窗口、敌人、体力、无敌帧等按后续计划实现。
