# M0-05A §4.2：五个关键姿势的数值表

日期：2026-09-21。适用：**UE 5.5.4 + SKM_Manny + 原版 CR_Mannequin_Body**。

本表用于 M0 的原地右手挥击占位。可以直接按数值填写，不必先凭感觉调旋转环。数值已在本工程模板 Rig 的独立临时实例中求值；**用户已完成五帧 key、连续播放、烘焙、独立播放与基础回归，M0-05A 验收通过，手动约 80 分钟**。表格保留供复现和复盘，下一步见 [M0-05B](M0_05B_DefensiveAnimations.md)。这是一版占位姿势，不是最终战斗动作的美术标准。

## 1. 这些数值填在哪里

填写对象是 **六个 FK 控制器**，由它们驱动肩／肘／腕对应骨骼。不要在 Skeleton Tree 中直接修改骨骼，也不要改人偶 Actor 的 Transform 或 Rig 的 Initial / Offset Transform。

1. 保持打开当前 `L_M0_AnimationLab` 和 `LS_M0_Attack_01`。你已经创建的目录是 `/Game/EmberTrial/Animations/Practice/Sequence/`，可以继续使用，无须为了原文的 `Sequences` 改名。
2. 在右上方 **Anim Outliner** 搜索一个完整控制器名称，单击搜索结果。
3. 确认右下方选中的是 **Anim Details**，区域标题就是该控制器名称，例如 `upperarm_r_fk_ctrl`。
4. 在这里的 **Location / Rotation / Scale** 填表。不要填到旁边普通 Details 中的场景 Actor Transform。
5. 视口旋转工具保持 Local，控制器 Space 保持模板默认。注意：视口的 Local 旋转环和这里的控制器数值不是同一个设置，单独切换旋转环不能纠正填错面板。

每个括号都按 **(X, Y, Z)** 顺序填写：

| 数值 | 单位／含义 | 界面对应 |
|---|---|---|
| Location | 相对控制器初始偏移的位置，单位 cm | 红 X、绿 Y、蓝 Z |
| Rotation | 相对控制器初始偏移的欧拉角，单位 ° | X=Roll，Y=Pitch，Z=Yaw |
| Scale | 相对缩放比例 | (1, 1, 1) 表示不缩放 |

例如 Rotation=`(0, -20, 15)`，就是红色 X 填 `0`、绿色 Y 填 `-20`、蓝色 Z 填 `15`。**填写表中的最终值，不是在原有数字上再加一次。** 若界面显示 Pitch / Yaw / Roll，必须按字段名称对应，不能照字段排列顺序抄括号。

这六个 FK 控制器的默认 Location≈(0,0,0)、Rotation≈(0,0,0)、Scale=(1,1,1)。`-0.0` 或约 `0.000001` 可视为浮点误差。右臂内部有镜像，但本表输入的 Scale 仍然全部是正的 1，不要改成 -1。

## 2. 固定条件

| 对象 | 五帧均使用的设置 |
|---|---|
| `arm_r_fk_ik_switch` | **不勾选／False**，使用 FK |
| `arm_l_fk_ik_switch` | **不勾选／False**，使用 FK |
| 下文六个 FK 控制器的 Location | **(0, 0, 0)** |
| 下文六个 FK 控制器的 Scale | **(1, 1, 1)** |
| 六个控制器的父级／Space | 保持模板默认，不做空间切换 |
| `global_ctrl`、`root_ctrl`、躯干、锁骨、头、腿、脚、手指等其余控制器 | 保持进入 §4.2 前的默认姿势，本次不调整 |
| 人偶 Actor Transform | 保持原摆放位置，Rotation=(0,0,0)、Scale=(1,1,1)，不打位移关键帧 |
| 帧率／播放范围 | 30 fps；Start=0，End=31 |
| 插值 | 本次数值版先使用 **Linear**，避免自动曲线过冲；验收后再润色 |

FK/IK 开关是单独的布尔控制器，不具有 Location / Rotation / Scale。若原轨道已经有开关关键帧，让它们在整个片段保持 False；不要让中间某帧自动切回 IK。

**“其余控制器保持默认”不等于“把全身所有骨骼 Location 填零”。** 骨骼本身包含骨长、父子偏移等信息；这些由 Rig 处理。此次只需要六行控制器，就可以完成这组上肢姿势。手指保留模板姿态，当前动作表现为挥击／推击，不要求握拳。

## 4. 推荐填写顺序

先完成 **第 0 帧**，再完成 **第 12 帧**。确认准备与前挥都正常后，再补 8、22、30 帧，减少整段做完才发现填错坐标的返工。

以第 0 帧为例：

1. 停止 Sequencer 播放，关闭 Auto Key；把时间指针移到 `0000`。
2. 确认两个手臂开关都是 False。
3. 搜索并选中 `upperarm_r_fk_ctrl`。
4. 在 Anim Details 将 Location 填成 `0 / 0 / 0`，Rotation 填成 `0 / -20 / 15`，Scale 填成 `1 / 1 / 1`。双击数值输入框输入，Enter 提交，避免拖动数字造成误差。
5. 保持这个控制器被选中，把鼠标移入动画视口，按 **S**。检查它的轨道在第 0 帧出现关键帧标记。若 S 未生效，使用该控制器 Transform 通道的 Add Key 菱形按钮，并检查 Location / Rotation / Scale 都有记录。
6. 对其余五个控制器逐个填写第 0 帧表格，并各自打 key。右手与左手即使 Rotation 全零，也要记录，防止继承此前试改的值。
7. 时间指针切到别的帧，再切回 0，确认数值和姿势保留。
8. 按同样步骤制作第 12 帧。之后补齐第 8、22、30 帧。第 30 帧可以重新填第 0 帧的表，也可以复制六个控制器在 0 帧的**关键帧点**到 30 帧。
9. 对这六个控制器的本次关键帧选择 Linear 插值（选关键帧点，右键查找 Linear；不要给整个人偶换成另一种动画轨道）。如菜单不一致，发菜单截图即可。
10. 在正面和侧面预览，再按主文档第 5 节烘焙。

编辑左臂时，五帧始终填写相同的值。不需要手动给每一帧补值，只在 0、8、12、22、30 五个关键帧记录即可，帧间由 Sequencer 插值。

如果此前在其他帧留下了试验 key、IK 动画或空间切换，可能影响结果。先确认它们的位置与用途，不要一键清空整个 Sequence。已有未保存资产请正常保存自己的进度；本轮我仅查看了窗口，没有替你保存或覆盖它们。
